## 第二阶段：创作链路

```text
用户设计简报 ── 输入校验 ── 提示词构建
                         │
               可选参考纹样文本字段
               （ID / 来源 / 视觉词 / 摘要）
                         │
              ┌──────────┴──────────┐
              │                     │
     OpenAI Images Provider   程序化 SVG Provider
       真实 PNG / 可计费        本地 / 不需密钥
              │                     │
              └──────────┬──────────┘
                         │
        data/generated/<id>.<png|svg> + <id>.json
```

Provider 统一返回图片字节、MIME、Provider 名称、模型/程序、尺寸和质量。OpenAI 适配器通过 `requests` 调用 Images API，密钥只从环境变量或 Streamlit secrets 进入运行时；缺少密钥、HTTP 错误、超时、无图片数据和非 PNG 响应都有显式错误。当前实现不会上传本地参考图或整个数据集。

程序化 SVG 是确定性几何备用生成器，独立标注为“程序化生成”。两类输出都保存 Prompt、用户参数和参考纹样 ID，但不会写回正式 CSV、RDF 图谱或文本证据库。

## 稳定身份

《中国传统纹样图鉴》使用内部命名空间 `wenyang:<原始三位 ID>`。HF 使用 `hf-<stage>:<完整相对图片路径 SHA1 前 16 位>`；原始 ID 和原始路径另列存储。这避免不同目录重复的 `001` 互相覆盖，也不会仅凭同名自动融合。

## Agent 调用顺序

1. `parse_design_request`：规则提取用户明确文字。
2. `search_patterns`：结构化字段宽召回。
3. `query_knowledge_graph`：对明确类别/寓意查图谱。
4. `retrieve_cultural_evidence`：TF-IDF 检索带来源片段。
5. `find_visual_neighbors`：有查询图时计算颜色特征距离。
6. `rank_candidates`：按字段维度匹配并归一权重打分，生成匹配项、未满足项、完整度和风险。时期只能由时代字段命中，未知值不能算成功。

每次运行把以上工具、记录数、证据数、方法和权重写入 trace，界面直接展示。Agent 不自主补写历史事实。

文本层严格区分三类内容：数据集描述可被检索但标记为未独立核验；未来外部资料需使用独立来源类型和 URL；系统设计建议只在输出层生成，不写回知识库，也不作为引用。

## 故障降级

- 原始数据缺失：应用给出准备指引，不加载 fixture。
- 图片缺失/损坏：跳过视觉索引并显示缺图，不影响文本和图谱。
- Plotly 不可用：视觉页回退到 Streamlit 原生散点图。
- 样本不足：不计算轮廓系数，明确提示。
- 没有文本命中：返回“现有资料不足以确认”。
- 在线 API/LLM 不可用：核心系统完全离线运行。
